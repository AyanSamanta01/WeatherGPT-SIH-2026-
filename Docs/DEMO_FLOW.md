# SIH Demo Flow

## Demo Scenario

### Step 1 — Location
User selects a location or allows geolocation.

### Step 2 — Current Weather
Show:
- Temperature
- Humidity
- Wind
- Rainfall
- Weather condition

### Step 3 — Conversational Query

User asks:

> Will it rain heavily tonight?

WeatherGPT:
1. Understands the question.
2. Gets the location.
3. Retrieves forecast data.
4. Checks risk information.
5. Generates a grounded answer.

### Step 4 — Map
Show the relevant weather/rainfall layer.

### Step 5 — Alert
Demonstrate a severe-weather warning or controlled demo alert.

### Step 6 — Language
Switch the response to an Indian language.

### Step 7 — Climate
Show historical rainfall/temperature trends.

### Step 8 — Decision Support
Demonstrate one use case such as:
- farmer advisory
- flood preparedness
- urban planning
- travel decision support

## Demo Principle
The demo should show a complete chain:

```text
Question
 → AI understanding
 → Real weather data
 → Analysis
 → Map/alert
 → Actionable answer
```
